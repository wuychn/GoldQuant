## 二、V8 新发现

### 🟠 R21. 文档默认值 ≠ 实盘配置，且差异是实质性的

`R3_ARCHITECTURE.md §6` 与 `TargetPortfolio` dataclass 默认值描述的是一套系统，`quant.yml` 实盘跑的是另一套：

| 项 | 文档/dataclass 默认 | 实盘 quant.yml | 影响 |
|---|---|---|---|
| `vol_lookback` | 60（文档自述"20→60 降噪"） | **14** | 波动/协方差窗口极短，与文档"降噪"说辞直接矛盾；vol target 噪声大 |
| `optimizer` | rank_vol | **mvo** | 实盘跑 MVO，但 §6 表格主要在描述 rank_vol/等权路径 |
| `covariance.method` | shrink | **ewma** | 实盘协方差口径与文档不同 |
| `alpha_weighted` | False | **true** | **死配置**：`target_weights` 中 MVO 分支优先，`alpha_weighted` 仅在 `optimizer!=mvo` 或 `covdict is None` 时才生效——配了等于没配 |
| `max_small_cap_pct`/`max_high_mom_pct` | — | 50 / 60 | 风格暴露上限松到几乎不约束，"风格约束"名存实亡 |

**修复路径**：以实盘 `quant.yml` 为准回填 §6 表格与 dataclass 默认；或反向把 `quant.yml` 改回文档口径。二者必须一致，否则"文档系统 ≠ 运行系统"，维护者据文档改参数不生效。

### 🟠 R22. 僵尸/疑似 r1 残留配置未对账死活

以下配置键出现在 `quant.yml`，但 r3 决策链未必仍读它们，需逐一核验"配置键 → 读取它的代码"：

- `gates.position`（强势 80 / 震荡 50 / 弱势 20 的 regime 仓位）：r3 `TargetPortfolio` 用 `target_vol`，不再走 regime 仓位（见 memory `r3-r1-retire` C6 待办）。**疑似死配置**。
- `continuous_position`（min 20 / max 80）：`TargetPortfolio` dataclass 无对应字段。**疑似死配置**。
- `gates.buy.intraday`（`drawdown_from_high` / `strong_day_chg` / `fund_improve_min_delta_wan` / `hard_net_outflow_wan` …，r1 风格盘中买入门禁）：但 §5b 说盘中买入 = 5 因子 z-score θ≥1.0（`compose_intraday_alpha`）。**两套盘中逻辑，哪一套真在跑？** 若 `risk_gate/executor` 仍读 `gates.buy.intraday`，文档与代码是两套系统；若没读，是僵尸。
- `min_listing_days`：gates=60，文档 §4.2≈120。**口径不一**。

**修复路径**：生成"配置键 → 读取代码"映射表，删僵尸、标注存活、同步文档。这是让"文档系统=运行系统"的一锤定音动作。

### 🔴 R23. "IC 驱动权重"建好了但没激活——实盘跑在手调默认权重上

`daily.py:97` 与 `alpha_builder.py:25`：无 `factor_weights_ts.yml` 时回退 `REGISTRY.weights()`（即各因子 `default_weight`，手调 0.4–1.0，非 IC 权重）。鉴于七轮从未跑过真实 `fit_weights`，**实盘此刻几乎可以确定跑在手调默认权重上**，ICIR/BH-FDR/walk-forward 只是"能力"，不是"现状"。

**后果**：push 推送的 α 值由手调权重合成，未经任何 IC 检验；"顶级量化"的因子选择在此处名不副实。
**修复路径**：跑 `python -m scripts.factors.fit_weights --walk-forward --fdr-alpha 0.05` 产出时变权重表，让 live 真正进 IC 模式。在此之前，push 文案应标注"权重=默认未校准"。

### 🔴 R24. 盘中择时层没有忠实回测，且存在 train-serve skew

`intraday_timing.py` 用 `spot_row_from_daily` 做日频代理回测，而该代理把盘中最具区分度的 `speed` 因子置为中性（代码注释自认）。于是盘中择时的"edge"是在一个删掉了核心信号的代理上测的——测不出信息量是大概率。而 live 用真实 spot（含 speed）。**盘中层——本系统最引以为区别性的部分——恰恰没有忠实回测**，且 live≠backtest。

V2–V7 七轮只盯着日频/value 层的 PIT（R14–R17），盘中层的 train-serve 偏斜**无人审计**。

**修复路径**：要么接真实分时/快照历史重放盘中层；要么至少把 `speed` 换成可由日内开/高/低/收估算的代理（如 `(close-open)/open` 作盘中走强，已部分有 `intraday_strength`），让代理回测覆盖所有 live 用的因子。

### 🔴 R25. 没有任何一条回测等于实盘真实交易路径

回测引擎（`engine.py`）在 T 开盘以日频 alpha + `TargetPortfolio` 成交；实盘（`ops/modes` 盘中块）在盘中以 `compose_intraday_alpha` + 分档仓位在最新价成交。**这是两个不同策略**：
- 回测：日频 alpha → 目标权重 → T 开盘一次性撮合。
- 实盘：日频 alpha top-N 作战池 → T+1 盘中 α_z≥θ 触发 → 最新价分档买入。

产出的权益曲线**不代表实盘行为**。盘中另有一个"edge 探针"（`intraday_timing.py`）但不产出组合权益曲线、不模拟滑点/T+1/仓位。**缺一条端到端、镜像实盘下单路径的回测**——这是顶级量化与"纸面 demo"的分水岭。

**修复路径**：写一个集成回测：日频选作战池 → 次日盘中触发（用日内 OHL 代理或历史快照）→ 分档买入 → 持仓 → L4 出场 → 权益曲线。让回测数字第一次对应实盘。

### 🟠 R26. 缺基准相对指标（A 股绝对 Sharpe 近乎无意义）

`§9` metrics 与 `metrics.py` 列表：Sharpe/Sortino/Calmar/MDD/turnover/胜率，**全是绝对值**。缺：
- 相对沪深300 / 中证500 / 中证1000 的**超额收益**
- tracking error、信息比 IR
- beta、相对回撤、超额回撤

A 股 beta 主导，绝对 Sharpe 无法判读策略是否真有 alpha。`research` 段已有 `bootstrap_samples:1000` / `min_oos_sharpe:0.5` 的显著性基建，但未接进 metrics 产出。V7 也想要 NW-Sharpe。

**修复路径**：`metrics.py` 加 benchmark 参 数（加载 `index_daily`），产出 excess return / IR / TE / beta / 相对 MDD；Sharpe 加 Newey-West 或 block bootstrap 置信区间。

### 🟠 R27. 因子共线，ICIR 加权不去做相关

16+ 因子中 `mom_20(-)` / `mom_60(+)` / `mom_120_20(+)` / `ma_spread` / `spread_accel_5` / `ma_slope_20` 共享同一"趋势"潜因子。`weights.py` 的 ICIR∝ 权重**对相关因子双重计数**——它只按 ICIR 缩放，不去相关。删 `mom_accel`/`downside_vol_60` 是对的，但剩余动量变体仍高度相关。

**修复路径**：在 `weights.py` 加因子协方差矩阵，用 ICIR 加权后再做残差正交（或用因子协方差逆加权的 ICIR）。至少在 IC 报告里输出因子间相关矩阵，让共线可见。

### 🟢 R28. 敏感性回测覆盖窄

`run.py:86` 的 sensitivity 仅在 `dates[-252:]`（最近一年）跑、只扫 `n_enter`/`target_vol` 两个参数。未覆盖真正敏感的杠杆：换手缓冲 `buffer_*`、ATR 倍数、`max_hold_days`、`sector_cap`/`concept_cap`。

**修复路径**：扩参数网格 + 全区间子样本（牛/熊/震荡分项）敏感性。

### 🟢 R29. §5 因子表过期（漏列 4 个基本面因子）

`R3_ARCHITECTURE.md §5` 自称"16 因子"并列出 16 行，**全部是价量/微观/主题/人气**。但 `factors/library/fundamental.py` 实有 4 个基本面因子在 REGISTRY 且默认权重非零：

| 因子 | 含义 | 方向 | 默认权重 |
|---|---|---|---|
| `ep_ttm` | 盈利收益率 1/PE | + | 0.8 |
| `bp` | 账面市值比 1/PB | + | 0.6 |
| `roe` | 净资产收益率 | + | 1.0 |
| `rev_yoy` | 营收同比 | + | 0.8 |

即：**value/quality 因子确实在 live alpha 里**（我初判"value 不在 alpha"有误，读 fundamental.py 后更正）。§5 表漏列它们 = 文档漂移。但 R17 bug（披露季不刷存量码）会让 `roe/ep_ttm` 的 TTM 随时间冻结过期——**它们的 IC 是否真实、是否被 fundamental_pit 正确填充，仍待一次真实 `fit_weights` 验证**。

**修复路径**：§5 表补 4 行；并验证 `metrics_as_of` 是否真把 `ep_ttm/bp/roe/rev_yoy` 注入 `bars.extras`（若 extras 为空，这 4 因子静默返回 None、等于没进 alpha，IC=0、被 BH-FDR 零权重——这种情况最难发现，需显式断言）。

### 🟠 R30. 推送文案给未验证信号披精确外衣（假精度）

push 推 `buy|rank=3|α=0.812|tw=12.0%|Δw=+12.0%|new_position`——小数点三位、权重百分比，呈现的是**未经证伪（很可能仍为手调默认权重，见 R23）**的信号的精确值，再被 LLM 包成"动量强/资金流入"的权威口吻。`LLM_OUTPUT_FORMAT` 禁系统黑话是好的，但精度≠可靠性。在一个从没出过真实权益曲线的系统上，这种文案会制造过度信任。

**修复路径**：在权重未校准期间，push 里 α 加后缀 `(默认权重，未校准)`；权重激活后再去掉。归因短语按因子 IC 置信度排序，弱因子不进文案。

## 三、因子缺口与补充建议

### 现状盘点

REGISTRY 实际因子族（`ALL_FACTORS`）：

| 族 | 因子 | 备注 |
|---|---|---|
| 动量 | mom_20(-) mom_60 mom_120_20 | 共线，见 R27 |
| 质量（价量代理） | eff_ratio_60 flip_rate_60 vol_60 | 全是价量派生，**无基本面质量** |
| 基本面 | ep_ttm bp roe rev_yoy | 已在 alpha，但仅 4 个，缺成长/质量/应计 |
| 位置 | dist_high_252 ma_spread spread_accel_5 ma_slope_20 | 趋势共线 |
| 量能 | vol_ratio_5_20 turnover_z_60 vol_price_corr_20 | |
| 资金/主题/人气 | flow_ratio_5 theme_mom hot_rank_z | 文档自承"常空或代理"，弱 |
| 盘中 | intraday_strength volume_ratio speed day_change turnover | 择时层，未忠实回测（R24） |

**结论**：价量/趋势/流动性已较全；**基本面维度单薄（仅 EP/BP/ROE/rev_yoy）**；**风险/行为因子几乎空白（无 IVOL/MAX/beta/Amihud）**。

### P0：基本面补全（数据已在 fundamental_pit，扩展 extras 即可）

> 价值/质量/成长三角是机构 alpha 的标配。当前只有价值的两角（EP/BP）+ 一个盈利能力（ROE）+ 一个成长（rev_yoy）。补齐：

| 待补因子 | 计算 | 方向 | 数据来源 | 理由 |
|---|---|---|---|---|
| `cfp` 现金流收益率 | 1/PCF（经营现金流TTM/市值） | + | fundamental_pit 扩 | 价值第三角；A 股现金流操纵难于利润，比 EP 更稳 |
| `gross_profitability` | 毛利 / 总资产（Novy-Marx） | + | fundamental_pit 扩 | 与动量低相关的经典 quality；A 股有效 |
| `accruals` | Sloan 应计 = Δ非现金营运资产 / 总资产 | - | fundamental_pit 扩 | 防"利润注水"，dir=-1 anomaly |
| `ni_growth_qoq` | 归母净利环比 | + | fundamental_pit 扩 | rev_yoy 是同比，缺环比成长动量 |
| `asset_growth` | 总资产同比增速 | - | fundamental_pit 扩 | 投资 anomaly，dir=-1 |
| `dividend_yield` | 近 12 月股息 / 市值 | + | fundamental_pit 扩 | 价值补全；A 股红利风格近年持续有效 |

> 全部可由现有 `fundamental_pit` 扩字段，无需新数据源。前提是先修 R17（披露季刷存量码），否则这些基本面因子会随时间冻结过期。

### P1：风险/行为因子（纯日线可算，无需新数据）

> 当前风险维度只有 `vol_60`（总波动）。顶级量化至少要有 IVOL/MAX/beta，它们与 vol_60 正交且在 A 股零售市场预期 IC 显著：

| 待补因子 | 计算 | 方向 | 理由 |
|---|---|---|---|
| `MAX_20` | 过去 20 日最大单日收益（Bali C-K） | - | A 股散户"彩票需求"强，MAX 高者后续跑输，预期 IC 显著负；当前完全缺失 |
| `ivol_60` | 市场模型残差波动（去 beta 后的个股波动） | - | 与 vol_60 不同：去市场 beta 后的纯个股风险，低 IVOL anomaly 在 A 股稳健 |
| `amihud_20` | 20 日均 \|日收益\| / 成交额 | + | 流动性溢价，与 turnover_z_60 正交（一个是换手、一个是价格冲击） |
| `beta_60` | 对基准的 60 日 beta | - | 低 beta anomaly + 组合风险控制双用途 |
| `size` | log 流通市值 | + | A 股小盘溢价；但**注意**：当前 size 只在中性化里作控制变量，单独作因子要防与中性化自指共线，建议在"去市值中性化后"再评估其残差是否还有溢价 |
| `reversal_5` | 近 5 日收益 | - | 短期反转在 A 股强；mom_20(dir=-1) 部分覆盖但窗口太长，独立 5d 反转更纯 |

### 因子补充的工程纪律

每加一个因子，必须同步走：IC 报告（`ic_report`）→ BH-FDR（`fit_weights --fdr-alpha 0.05`）→ 不通过自动零权重 → walk-forward 时变表 → 回测对比 Sharpe 是否提升。**不达标不进 alpha**——否则 R23 的"手调权重"问题会随因子增多而放大。

## 六、结论

V7 把代码层结构性硬伤清零到 A-，本评确认这一点。但 V8 的核心判据不在代码：**GoldQuant 至今没有一条经过真实数据证伪的权益曲线**。R23（权重未激活）、R24（盘中 train-serve skew）、R25（回测≠实盘路径）合在一起意味着——即便代码再干净，"对标顶级量化"目前是断言，不是事实。

**本系统最近"顶级量化"的一步，不是再抠一行代码，而是把真实数据灌进去，看一眼超额收益曲线。** 那一眼会同时证伪/证实七轮修补，并指出 §三的因子缺口里哪一个最值得补。在那一眼出现之前，新增因子、调参数、改文案都是在未校准的地基上盖楼。

**阶段判定**：代码层已达"可上小资金纸面/实盘验证的全部前置条件"。下一步必须是验证，不是再审计。
