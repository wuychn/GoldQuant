## 运维清单

```bash
# 1. walk-forward 权重（默认模式，勿加 --static）
python -m scripts.factors.fit_weights --start 2023-01-01 --end 2024-12-31

# 2. 日更（含 listing + 因子快照）
python -m scripts.data.update_daily

# 3. 历史快照回填（可选）
python -m scripts.data.backfill_factor_snapshots --start 2024-01-01 --end 2024-12-31

# 4. 回测（strict + IC 权重 + 敏感性）
python -m scripts.backtest.run --start 2022-01-01 --end 2024-12-31 --sensitivity
```
