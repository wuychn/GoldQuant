# 架构

当前产品是 5 板短线战术：盘后复盘写次日计划，盘中按计划推送买卖。不接券商。

## 闭环

| 时间 | 做什么 | 入口 |
|---|---|---|
| 20:10 | 补当天涨停族和观察票日 K，写次日计划，飞书复盘 | `scripts.tactic.close` |
| 09:30–15:05 | 每 3 分钟：尾盘买、随时卖，飞书 | `scripts.tactic.intraday --loop` |

状态在 `$QUANT_HOME/store/tactic/state.json`。观察票日 K 在 `store/tactic/bars/`。全市场日线不是策略输入。

## 策略代码

`quant/tactic/`

- 情绪四灯：跌停家数、炸板率、2 进 3、昨涨停溢价。任一停手灯红则不开新仓；预警只做计划内。
- 观察池只留连板 ≥ 5。两日收盘跌停、A 杀、回撤超限则删除。仍在连板的只观察。一字跌停断板、利空被动砸开都不因此直接删除：一字跌停仍算断板，可进模式 B；没有利空数据，不单列判断。其余硬条件照常删。
- 模式 A：严重异动之后的缩量回踩。调整前最高收盘价到调整期最低收盘价，主板回撤 >20% 删除，双创 >30% 删除。
- 模式 B：≥5 板后收盘不再涨停的横盘。断板前最高收盘价到横盘期最低收盘价，主板回撤 >15% 删除，双创 >20% 删除。收盘跌破断板日最低价同样删除。
- 卖出：约 +10%、冲高回落、B 次日反弹卖、跌停否则次日集合竞价。不加仓、不做 T。
- 当日严重异动临界涨幅读东财 `price-anomaly/list`，不在本地重算。已触发或停牌则观察，不删除。

模式 A 的起点是东财严重异动历史里该票最近一次已触发的日期，不在本地用日线重算。当日临界涨幅仍读东财实时列表。

## 数据

依赖方向：`common ← quant ← {app, scripts}`。`quant/` 不 import `app/`。

行情经 `quant/data/sources` 的四类协议换源：一个 facade 方法只走一个源，未实现的源抛 `NotImplementedError`。换源改 `quant/config/quant.yml` 的 `data.sources`。

5 板读：观察池日 K、涨停池、炸板/跌停/昨涨停、实时 spot、东财严重异动列表和已触发历史。当天 5 板、观察和持仓的资金流与龙虎榜另存 `store/tactic/ml/`，买卖不读。
