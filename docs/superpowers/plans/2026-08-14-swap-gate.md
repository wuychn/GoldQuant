# SwapGate 实现计划

> **For agentic workers:** 按任务顺序 TDD 实现；每任务先写失败测试再写最小实现。

**Goal:** 实现独立 SwapGate：分数差+ADV 成本双门槛换仓，ATR+MA20 趋势软标签，连续 2 日趋势失败强制卖；接入 TargetPortfolio / 配置 / 纸面 sell_watch。

**Architecture:** `trend_state` 判定趋势；`swap_gate` 产出目标持仓集合；`TargetPortfolio` 在 enabled 时用 gate 替代纯 rank buffer；exit/sell_watch 与趋势强制卖对齐。

**Tech Stack:** Python、pytest、现有 CostModel/SlippageContext、TargetPortfolio、ExitConfig

## Global Constraints

- `max_stocks=3`, `n_enter=3`, `n_exit=8`
- 换仓必须同时过 δ 与 k×ADV 成本
- `keep` 不可被追第一名踢掉
- 不以日历换仓、不以 MVO 为主路径
- 文档：`docs/CONFIG.md` / `OPERATIONS.md` 同步
